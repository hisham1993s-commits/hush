# Hush

A simple ad blocker for Android, made by Hisham.

- One button to turn it on or off, and it works on Wi-Fi and mobile data
- Blocks ads, trackers and malware sites for every app, using the same lists as Pi-hole
- Everything is checked on the phone. No account, and nothing is sent to a server

## Install

1. Download **Hush.apk** from the [latest release](https://github.com/hisham1993s-commits/hush/releases/latest)
2. Open it and allow installing from this source
3. Open Hush and tap the big button

Hush checks this page for new versions and offers to update itself.
